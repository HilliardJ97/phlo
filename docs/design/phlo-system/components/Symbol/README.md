The split bubble is Phlo's symbol: a vermilion half-circle (voice) and an ink square with a tail (the page), separated by a small gap.

- **Grammar:** round = voice, square = page, tail = speech, gap = transformation. Every product symbol (Talk, Partner, Scribe, Settle, Publish) is built from only these parts.
- **Sizes:** 16px minimum. The app icon is the Sumi-theme symbol on a sumi tile at 82%.
- **Don't:** round the square, close the gap, flip it, outline it, or recolor it in idea colors.
- The SVGs are in the Logos and Symbols asset groups, with light and dark versions for the symbol, lockup and wordmark.
