A flat sticky-tab flag that marks anything Phlo pulled out, flagged or researched.

- The flag sits outside the writing column's right edge, aligned to the first line of its block.
- `tab` means Phlo flagged it. An idea color (`cobalt`, `teal`, `saffron`) means the block belongs to that theme.
- A pulled-out key idea also becomes a `paper-raised` block with a `hairline` border and a mono label.
- Text never goes inside the flag.
