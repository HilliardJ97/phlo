The Partner/Scribe switch sets Phlo's role for a session, and the corner label tells the room which role is on.

- **Partner** (default when alone): tangent tabs, stall questions, structure suggestions.
- **Scribe** (someone's watching): organizing only, with no added ideas, prompts or research. Turns on Room view.
- In Room view, the switch hides and only the corner label stays: `SCRIBE · YOUR WORDS ONLY`, with a small vermilion dot while listening.
- Copy is always these exact words. Never "interview mode," "assistant" or "AI off."
