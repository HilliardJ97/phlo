A solid `vermilion` disc that is the mic, the recording state and the app icon.

- **Idle:** a hairline ring in `ink-muted`. **Listening:** solid vermilion, breathing between scale 1 and 1.25 with input level. **Settling:** 35% opacity while Phlo organizes.
- It's the only vermilion element on screen. In Talk mode, it's the only UI element on screen at all.
- Default size is 40px, centered at the bottom with `space-5` clearance.
